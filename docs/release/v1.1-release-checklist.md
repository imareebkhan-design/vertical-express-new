# Version 1.1 Release Readiness Checklist

This document tracks the signoff state for each module of Vertical Express Version 1.1 prior to production deployment.

## 1. Module Signoff Status

### Core Commerce & Cart
- [x] **GST Calculations:** Verified intra-state and inter-state GST split logic runs on the server.
- [x] **Integer Paise Math:** All prices, discounts, and totals are computed using integers (Paise) to eliminate floating-point rounding errors.
- [x] **Quantity Clamping:** Cart item quantities are verified and auto-clamped dynamically on cart fetch when warehouse stock levels change.

### Inventory & Warehouses
- [x] **Warehouse Resolution:** Customer addresses mapped to correct warehouses based on pincode.
- [x] **Atomic Checkout Decrement:** Implemented row-level locks on inventory during checkout transactions.
- [x] **Overselling Prevention:** Validated that checkout operations fail when order quantity exceeds warehouse stock.
- [x] **Stock Restoration:** Stock is correctly restored back to warehouse inventory on cancellations.

### Payments & Security
- [x] **Production Mode Safety:** Confirmed payment gateway selection raises exceptions on startup if credentials are missing in production mode, blocking silent dummy fallback.
- [x] **Razorpay Webhooks:** Verified signature checks and webhook event idempotency (prevents duplicate processing).
- [x] **Secrets Scan:** Inspected code to ensure no plaintext tokens, private keys, or passwords are hardcoded.

### Performance & Cache
- [x] **Server Caching:** Configured Next.js `unstable_cache` for `getDeals`, `getRelatedProducts`, and `listCategories`.
- [x] **DB Indices:** Added composite indices to payments (`gatewayOrderId`, `gatewayPaymentId`) and catalog models to optimize load times.
