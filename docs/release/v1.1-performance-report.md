# Version 1.1 Performance & Benchmark Report

This document records the latency metrics, cache hit rates, and concurrency benchmark results for Vertical Express Version 1.1.

## 1. Concurrency Benchmarks

### Concurrent Search Spikes (10, 25, and 50 users)
- **10 users:** Avg Latency = **504.60ms** (Total = 5046ms)
- **25 users:** Avg Latency = **991.44ms** (Total = 24786ms)
- **50 users:** Avg Latency = **675.74ms** (Total = 33787ms)

### Heavy Administrative BI Reports (30 parallel admins)
- **30 users:** Avg Latency = **1051.27ms** (Total = 31538ms)

### Concurrent Checkout Flash Sale (15 concurrent checkouts)
- **Stock Limit:** 5 items
- **Successes:** 5 orders (33%)
- **Failures:** 10 orders (67%)
- **Latency:** Average checkout duration = **649.53ms**
- **Safety:** Transaction locks blocked double selling, leaving final stock at exactly 0.

---

## 2. Caching Optimizations
By wrapping `getDeals`, `getRelatedProducts`, and `listCategories` in Next.js `unstable_cache` with revalidation tags, database hits for static reads are reduced to nearly zero, significantly improving First Contentful Paint (FCP) and Time to First Byte (TTFB).
